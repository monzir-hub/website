Flask app with MongoDB behind NGINX, packaged as Docker images and deployed to Kubernetes.

Tech Stack: Docker, Kubernetes, NGINX, Flask, MongoDB.

AWS Multi-Tier Architecture

Layered Web Stack in AWS

Isolated public and private tiers with load balancers and hardened network boundaries.

Problem: Deploy a resilient web tier with strict separation between public entry points and private application servers.

Architecture: Custom VPC with public ALB to Nginx servers, internal load balancer to Apache servers in private subnets, security groups enforcing least privilege.

Tech Stack: AWS VPC, ALB, EC2, security groups, subnets, Nginx, Apache.

What I Implemented: Provisioned VPC, subnets, routing, load balancers, and security group rules to isolate layers and allow controlled traffic flow.
